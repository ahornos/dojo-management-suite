# Dojo Management Suite (DMS)

Dojo Management Suite is a robust, full-stack platform designed to streamline the operations of martial arts dojos. Built inside a Turborepo monorepo, it leverages a microservices architecture (NestJS, PostgreSQL, Redis) to handle complex domain rules such as belt/stripe progression, financial management (including SEPA-compliant recurring billing), and role-based access control for staff and students.
